# 勉強コーチ（StudyNudge）

## GitHubでAPKを作る手順
1. GitHubで新しいリポジトリを作る（Private可）。
2. このzipを展開し、**中身をすべて**（`.github` フォルダを含む）リポジトリにアップロードする。
   - `.github/workflows/build.yml` がリポジトリにあることを必ず確認。
3. 「Actions」タブ → 「Build APK」が自動で走る（走らなければ Run workflow）。
4. 成功したら、実行結果ページの一番下「Artifacts」から `app-debug-apk` をダウンロード → zipを展開すると `app-debug.apk`。
5. スマホにインストール。
6. 失敗したら、赤い×の実行 → 失敗したステップのログ画面をスクリーンショット。

## アプリ初期設定
1. 「他のアプリの上に表示」「使用状況へのアクセス」「位置情報・カレンダー・通知」を許可
   （押せない場合: 設定 > アプリ > 勉強コーチ > ︙ > 制限付き設定を許可）
2. Gemini APIキーを入力（Google AI Studio で無料取得）。モデル名は変更可能。
3. 自宅・学校・最寄り駅・塾を、地図をタップしてピンで登録
4. 「今すぐテスト表示」→ホーム画面などで待つと画面上部にメッセージが出る
5. 「見守りを開始」

## 仕様メモ
- 地図は OpenStreetMap（APIキー不要）。
- カレンダーは端末に同期されたGoogleカレンダーを読み取り（ログイン不要）。
- 学校・塾の近くにいる時、予定の進行中は声かけしません。
- 早朝: 設定時刻前に使い始めて1〜5分で「おはようございます」系（1日1回）
- 夜更かし: 就寝時刻以降の使用で60分に1回
- AIに繋がらない時は定型文を表示。原因はアプリ画面の「直近のエラー」に出ます。
